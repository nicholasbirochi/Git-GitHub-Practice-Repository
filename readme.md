# Exercícios de Git e GitHub

Repositório de prática do curso de Git e GitHub da DevSuperior. As páginas HTML servem de material para exercitar alterações, commits e organização do histórico.

## Arquivos

- `index.html`: página inicial.
- `Sobre.html`, `blog.html` e `vendas.html`: outras páginas do exercício.

Abra `index.html` no navegador para ver os arquivos. Este é um exercício de versionamento; não há servidor ou aplicação de vendas implementada aqui.
